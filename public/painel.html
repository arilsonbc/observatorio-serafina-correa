Como os números são calculados

Empresas são agrupadas por identificador. A API de licitações não identifica os vencedores; o ranking de processos com contrato conta processos distintos vinculados a contratos e não equivale a vitórias. pagamentos são agregados por fornecedor no mês de pagamento, contratos pela data de contratação. Um contrato não comprova pagamento. Na folha, o mês representa a competência; bruto, descontos e líquido são apresentados separadamente. O acumulado soma somente os registros disponíveis, em valores nominais.

Cobertura e atualização

Nenhum arquivo importado. A ausência de registros não significa ausência de despesas.

A integração consulta automaticamente a API oficial ao abrir o painel, ao trocar o ano e a cada 30 minutos enquanto a página está aberta. A coleta diária sincroniza uma cópia persistente no servidor, inclusive com o site fechado. O painel consulta essa cópia e mostra a data efetiva da coleta. Histórico consultável nesta integração: 2017 em diante. A API retornou HTTP 500 nos testes de 2014 a 2016; isso não comprova ausência de registros nesses anos. O botão Atualizar recarrega a cópia disponível; não força uma nova coleta municipal. CSV é uma opção de consulta separada. Nenhum CPF ou dado bancário é armazenado pelo painel.

Importar dados municipais

Use um CSV UTF-8 consolidado. Separador: ponto e vírgula. A importação substitui a base anterior.

Tipos: licitacao, pagamento, contrato, salario. Data: AAAA-MM-DD. Valores: 1234,56. Cada linha precisa de um registro_id único.

Para licitações, informe apenas resultados vencedores. Repita o processo_id para itens do mesmo processo: será contada uma única vitória por empresa.
